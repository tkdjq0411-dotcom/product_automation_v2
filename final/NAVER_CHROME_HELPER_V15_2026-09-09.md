# NAVER Chrome Helper V15

- 실제 구매영역의 큰 표시가격을 우선 사용하도록 가격 추출 보정
- 배송 영역 내부의 실제 배송비만 인정
- 상품 이미지 전체를 페이지 전역이 아닌 좌측 대표 이미지 + 하단 갤러리로 제한
- 갤러리의 `현재/전체` 표시와 다음 버튼을 이용해 숨겨진 썸네일까지 순회
- 옵션 팝업이 실제로 열린 경우 그 팝업 내부 값만 수집하여 리뷰/본문 오수집 차단
- `옵션 선택(필수)`과 `추가 옵션`을 화면 위치 기준으로 분리
- 추가 옵션 각 드롭다운을 열어 내부 옵션값(+금액/품절 표시 포함)을 수집
- 품절은 활성 구매버튼이 있으면 판매 가능, 명시적 품절/비활성 구매버튼일 때만 품절 처리
- Chrome Helper version 2.3.0
