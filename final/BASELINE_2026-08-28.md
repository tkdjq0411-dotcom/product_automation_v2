# B2B SaaS 기준본 - 2026-08-28

이 폴더를 2026-08-28 이후 개발의 단일 기준 프로젝트로 사용합니다.

## 통합 판단
- 발전본(로컬 SQLite 기반)을 기준본으로 유지했습니다.
- 비교본의 Supabase REST 구조를 확인했지만, 발전본이 이미 정상 동작하는 저장소 호환 레이어와 UI/재고 기능을 포함하므로 성공한 코드를 대규모 변경하지 않았습니다.
- 기존 `app/db/supabase.py` import 경로는 유지되며 현재 실제 저장소는 SQLite 호환 레이어입니다.
- 실제 Supabase 전환은 별도 검증 후 진행해야 하며, 이번 기준본 확정 과정에서 성공한 DB 동작을 강제로 교체하지 않았습니다.

## 기준 실행
1. `pip install -r requirements.txt`
2. `python -m uvicorn app.main:app --reload`
3. 브라우저에서 `/health`, `/docs`, `/web/` 확인

## 보호 원칙
정상 작동이 확인된 기능은 이후 일정에서도 불필요하게 리팩터링하지 않고, 실패한 기능과 직접 연관된 부분 위주로 수정합니다.
