# 네이버 소싱 1단계 옵션 진단 V54

- 기준본: V53
- 확장프로그램 버전: 2.41.0
- 상품명, 매입가, 배송비, 이미지, 일반옵션, 종속옵션, 추가옵션 수집 로직은 유지합니다.
- 일반옵션 트리거 클릭 성공/차단/오류를 기록합니다.
- 각 옵션 항목의 실제 클릭 대상과 같은 행의 buyer-visible 문구를 기록합니다.
- 클릭 전후 구매영역의 원화 가격 후보와 `+/-원` 감지 결과를 기록합니다.
- DOM 수집값, 내부 상태 수집값, 전용 옵션가격 수집값, 최종 표시값을 한 번에 비교할 수 있습니다.
- 진단정보는 영구 SQLite/Supabase DB에 저장하지 않고 최근 수집 미리보기에만 임시 보관합니다.
- B2B 수집 결과에서 `일반옵션 진단`을 펼쳐 확인하거나 `진단내용 복사` 버튼으로 복사할 수 있습니다.
- 구매하기, 장바구니, 선물하기, 찜하기, 톡톡, 리뷰 관련 클릭 차단을 유지합니다.
- 최대 옵션 수집시간 60초와 B2B 대기시간 75초를 유지합니다.

## 1단계 완료 판정 방법

같은 문제 상품을 한 번 수집한 뒤 다음 수치를 확인합니다.

- 실제 항목 클릭: 5개가 정상 기대값입니다.
- `+/-금액 감지`: `4#`부터 `7#`까지 4개가 정상 기대값입니다.
- 값이 다르면 펼친 진단내용을 복사하여 다음 수정의 근거로 사용합니다.
