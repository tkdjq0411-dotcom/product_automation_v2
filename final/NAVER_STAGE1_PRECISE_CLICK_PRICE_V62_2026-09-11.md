# 네이버 1단계 실제 클릭 가격 수집 V62

- 확장프로그램 버전: 2.49.0
- 목록만 읽고 마지막 단계라고 판단하던 방식을 제거했습니다.
- 각 옵션값을 실제 클릭한 뒤 아래에 새 선택창이 생성되는지 다시 확인합니다.
- `길이 → 호수`, `종류 → 색상 → 호수` 등 동적 종속옵션을 끝까지 따라갑니다.
- 마지막 호수도 실제 클릭하고 해당 행의 `+/-` 금액과 품절 상태를 저장합니다.
- 체크박스형 마지막 옵션은 확인 후 가능한 경우 즉시 해제합니다.
- 동일 그룹과 동일 완성 조합 중복 제거를 유지합니다.
- 전체 최대 2분과 구매 관련 버튼 클릭 방지를 유지합니다.
