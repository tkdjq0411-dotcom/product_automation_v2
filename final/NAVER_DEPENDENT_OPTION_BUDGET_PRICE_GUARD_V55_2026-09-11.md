# 네이버 종속옵션 수집 보강 V55

- 확장프로그램 버전: 2.42.0
- 일반옵션, 추가옵션 및 기존 수집 구조는 유지했습니다.
- 옵션 수집 기본 제한은 60초로 유지하되 실제 항목이 발견되거나 클릭되는 동안 최대 180초까지 자동 연장합니다.
- 부모 옵션 선택 후 생성되는 자식 옵션 목록을 계속 수집할 수 있도록 진행 시 제한시간을 연장합니다.
- 옵션 호수와 수량 숫자가 결합된 비정상 값이 매입가로 들어가는 것을 차단했습니다.
- 화면 가격이 구조화된 상품 가격보다 비정상적으로 큰 경우 구조화된 실제 상품 가격으로 복구합니다.
- 무한대기 방지를 위한 최대 180초 상한은 유지합니다.
- SQLite 초기화 및 데이터베이스 덮어쓰기 변경은 없습니다.

## 확인 대상

1. 매입가가 실제 판매가 4,500원으로 표시되는지 확인
2. `봉돌선택` 아래 두 종류가 수집되는지 확인
3. 각 봉돌을 선택했을 때 표시되는 `옵션선택/호수` 값이 종속 옵션으로 수집되는지 확인
4. 데이터가 많은 경우 60초가 지나도 진행 중이면 수집이 이어지는지 확인
5. 수집이 멈춘 경우에도 180초 이내에 강제 종료되는지 확인
