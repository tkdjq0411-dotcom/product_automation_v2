# B2B SaaS 최대 기능 구현본 — 2026-09-01

이번 버전은 외부 서비스의 실제 API 자격증명 없이 로컬에서 구현 가능한 운영 기능을 최대한 연결한 기준본입니다.

## 실제 동작
- 회원가입 / 로그인 / 로그아웃(상단 계정 메뉴 + 설정)
- 공급처 CRUD
- 상품 CRUD / 자동 계산 / SELL·STOP / 최저 판매 가능가
- 상품 소싱 CRUD
- 경쟁가 저장 / 상품별 가격 자동화 규칙 / 자동 가격 조정 / 손익 안전선 미만 자동 STOP / 회복 시 자동 재계산
- 가격 자동화 이력
- 주문 등록 / 취소 / 삭제
- 주문 → 발주 준비 → 결제 완료 → 배송 등록 → 배송 완료 상태 연동
- AI 상품 제작 로컬 초안(제목, 상세 설명 구조, 구매 포인트, FAQ, 키워드)
- CSV/XLSX 상품 대량 등록/내보내기
- 주문 운영 리포트 CSV
- 운영 요약 리포트 API
- 네이버/쿠팡/11번가 채널 연결 설정 메타데이터
- 활동 로그
- 설정 내 로그아웃
- 요금제/사용량 기존 기능 유지
- 프로젝트 ZIP 교체 후에도 유지되는 외부 SQLite DB 구조 유지

## 외부 API가 있어야 실제 자동화 가능한 부분
- 네이버/쿠팡/11번가 실시간 주문 자동 수집
- 판매채널 실제 상품 등록/수정/판매중지 API 호출
- 경쟁사 가격의 실시간/1시간 주기 외부 수집
- 공급처 자동 주문 및 결제
- 택배사 실시간 배송 위치 조회
- 외부 생성형 AI 모델 기반 이미지/상세페이지 생성

위 기능들은 현재 화면/데이터 구조와 로컬 업무 흐름을 먼저 만들어 두었으며, 실제 서비스 자격증명이 생기면 커넥터를 연결하는 단계가 남아 있습니다.
