V79 / Chrome Extension 2.61.12

실행: 기존 실행방법 유지. 서버 재시작 후 chrome://extensions에서 기존 도우미의
폴더를 final/chrome_extension/naver_source_helper로 지정하고 새로고침하세요.
확장프로그램 버전 2.61.12 확인 후 B2B 화면도 새로고침하세요.

수정 사항
- B2B 결과 대기 75초 -> 225초(탭 로딩 및 서버 전송 여유 포함).
- 수집 시작 기준 180초 deadline. 옵션 탐색은 stop flag로 중단하고 누적값 전달.
  브라우저 이벤트 루프 정지/탭 스로틀링 시 실제 콜백 시각은 지연될 수 있음.
  서버 전송 및 ACK는 수집 180초와 별개이며 네트워크 상태에 따라 추가 시간 소요.
- 중간 옵션 DFS, 마지막 목록은 각 행 발견 즉시 accumulator에 기록.
- 전체 부모 경로/단계/그룹/ID 기반 실제 클릭 직전 lock. click 예외 후 대체 클릭 제거.
- 드롭다운 재열기 허용, 가상 목록 부모 찾기는 스크롤만 사용.
- 비활성 다음 버튼도 단계로 계산, 내부 probe의 단계 정보 활용(최대 30단계).
- COMPLETE/PARTIAL/FAILED_WITH_NO_DATA 전달 및 PARTIAL 미리보기 안내.
- 음수 옵션 가격 보존, 서버의 10000개 조합 잘림 제거.
- 옵션 표시문구와 ID 보존. 최종 정규화가 수집한 조합을 축약하지 않도록 보호.
- 추가옵션은 전용 semantic 버튼을 열고 읽기만 수행.
- storage.session에 탭별 소유권 보존, 서버 ok:true ACK 뒤 해당 임시 탭만 닫고 복귀.
- 상품 기본정보/기존 API 경로/실행 구조 유지. network_hook.js는 검토 후 변경하지 않음.

node tests/naver_v79/collector.test.cjs
node tests/naver_v79/background.test.cjs
python tests/naver_v79/server_test.py
1/2/3/4/7/30단계, DFS 순서 및 개수, 반복 부모 라벨, +/- 및 품절,
180000ms 경계, 시간 만료 누적값/분기 오류 누적값, 클릭 throw 후 재시도 방지,
부모별 클릭 독립성, 10001개 서버 정규화, ACK 거절, 임시 탭만 닫기/원래 탭 복귀 검증.
JS/Python 구문 검사 통과.

제약 및 실사용 확인 필요
- 다음 단계가 DOM에 전혀 없고 passive 내부 데이터에도 없으면 클릭 없이 마지막
  단계 여부를 증명할 수 없습니다. 단일 단계이며 스키마 증거가 없으면 PARTIAL 표시.
  이런 상품의 모든 숨은 단계를 보장한다고 주장하지 않습니다.
- 네이버 실제 지연/가상 목록/상품별 DOM, 실제 로컬 POST 및 브라우저 sleep 복구는
  대표님 PC에서 확인 필요. 모의 검증으로 실제 상품 16개 조건 전체 PASS를 주장하지 않음.
- 서버 ACK는 기존 /sourcing/browser-capture의 미리보기 캐시 저장 완료를 뜻합니다.
  기존과 동일하게 상품의 영구 등록은 B2B의 확인/수정 후 저장 단계입니다.
- 전체 브라우저 종료/PC 종료 후 수집 재개는 이번 수정 범위에 포함되지 않습니다.
