# 2026-09-01 V1 계산엔진

## 단일 계산식
- 기본원가 = 구매가 + 국제배송비 + 국내배송비
- 수수료 = 판매가 × 수수료율
- VAT = 판매가 × VAT율
- 총비용 = 기본원가 + 수수료 + VAT
- 순이익 = 판매가 - 총비용
- 마진율 = 순이익 / 판매가 × 100 (판매가 0이면 0%)

## 구현
- Decimal 기반 계산으로 부동소수점 오차 최소화
- 금액 0.01원 단위 ROUND_HALF_UP
- 상품 등록 시 자동 계산 및 DB 저장
- 상품 수정 시 자동 재계산 및 DB 저장
- 독립 계산 API와 상품 계산을 동일 엔진으로 통합
- 0원/적자/소수점/수수료 0/VAT 0 처리
- 음수 금액 및 0~1 범위를 벗어난 세율 차단
- 계산 API 사용자 데이터 격리/상품 소유권 검증
- 기존 계산 API 필드 호환 유지
- 상품 목록/상세에서 수수료, VAT, 총비용, 순이익, 마진율 확인 가능
