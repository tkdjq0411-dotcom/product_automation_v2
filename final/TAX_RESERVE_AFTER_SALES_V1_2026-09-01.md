# 세금 적립·취소/반품/교환 자동화 V1

## 세금 적립

- 순이익 안전 적립률 기본 10%
- 소득세 추가 적립률 사용자 설정
- 세전 순이익, 총 적립금, 실제 사용 가능 이익 표시
- 부가세 포함 매출/매입의 10/110 기준 예상 매출세액·매입세액 공제·납부액 표시
- 취소 완료 주문은 매출·이익·적립금 합계에서 즉시 제외

## 취소·반품·교환

- 고객 채널 이벤트 수신 API 제공
- 미발주 또는 미결제·미출고 주문은 발주 차단 후 즉시 취소 완료
- 공급처 결제 후 출고 전 주문은 공급처 취소 확인 필요 상태로 전환
- 출고 주문 및 반품/교환은 회수·공급처 확인 필요 상태로 전환
- 동일 요청 중복 처리 방지
- 주문·발주 상태 및 활동 로그 동시 갱신

## API

- `GET /tax-reserve/summary`
- `PATCH /tax-reserve/settings`
- `GET /after-sales/`
- `POST /after-sales/`
- `POST /after-sales/channel-event`

실제 공급처 사이트의 자동 취소는 공급처별 주문 API 또는 공식 제휴 API가 연결된 경우 어댑터를 추가해 완전 자동화합니다. API가 없는 공급처는 성공으로 처리하지 않고 수동 확인 필요 상태로 남깁니다.
