# 네이버 URL 내부 데이터 우선 수집 V64

## 확장프로그램

- 버전: 2.51.0
- 기본 방식: URL 상품 페이지의 내부 상태·JSON·네트워크 응답 우선 수집
- 클릭 방식: 내부 데이터에 필수 옵션 조합이 없을 때만 보완 실행

## 수집 범위

- 실제 전체 상품명, 현재 판매가, 배송비, 공급 상태
- 대표 이미지 및 상품 이미지
- 필수 옵션 그룹과 값
- 부모→자식 종속 옵션 조합
- 추가 옵션 그룹과 값
- 옵션별 추가·차감 금액
- 옵션별 품절 상태

## 판단 순서

1. 내부 상품 데이터 전수 탐색
2. 옵션 구조와 조합 완성도 판단
3. 완성된 경우 클릭 없이 즉시 정규화
4. 불완전한 경우 누락된 구조 확인을 위한 DOM 클릭 보완
5. 중복 제거 및 2차 누락 검사

## 확대된 수집 한도

- 네트워크 응답 보관: 최대 250개
- 응답 본문: 건당 최대 10MB
- 옵션 그룹·추가옵션 그룹: 각각 최대 100개
- 옵션 조합: 최대 10,000개
- 그룹별 옵션 값: 최대 2,000개
- 이미지: 최대 100개

수집값을 추측해서 생성하지 않으며, 내부 데이터와 실제 화면 모두에서 확인되지 않는 값은 검토 대상으로 남긴다.
