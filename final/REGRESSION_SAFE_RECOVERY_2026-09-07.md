# 회귀 방지 복구본

기준: 상품 등록/수정/삭제가 정상 동작하던 `PRODUCT_CRUD_RESTORED_NAVER_CAPTURE` 기준본.

## 복구/보존
- 상품 등록 / 수정 / 삭제 / 검색 유지
- 소싱 확인/수정/저장 항상 유지
- 공급처 자동 생성/기존 공급처 재사용 유지
- 네이버 일반 Chrome 직접수집 유지

## 소싱 회귀 방지
- `browser`, `NAVER`, `로그인`, 에러페이지/시스템오류를 상품명으로 저장하지 않음
- `nid.naver.com` 로그인 리다이렉트 URL을 공급처 상품 URL로 덮어쓰지 않음
- `.js`, `sp_u_`, `ntm.pstatic`, 공용 UI 이미지를 상품 이미지로 저장하지 않음
- 사용자가 붙여넣은 원본 상품 URL을 우선 보존
- 실제 이미지 전체 배열 저장(`image_urls_json`) 및 확인 화면 갤러리 표시
- 옵션 그룹/조합 JSON과 사람이 읽는 옵션 텍스트를 함께 보존
- 자동수집 실패/부분수집이어도 확인/수정 후 저장 버튼 유지
- DOM 실페이지 수집값은 실제로 검증된 필드만 적용

## 내부 회귀 테스트
- 상품 CRUD: 등록 → 수정 → 목록 → 삭제 PASS
- 소싱 저장 + 공급처 자동 생성 PASS
- 5개 이미지 배열 저장 PASS
- 옵션1 그룹 저장 PASS
- 매입가/무료배송(0원) 저장 PASS
- Python compile / JS syntax PASS

실제 네이버 네트워크 데이터는 사용자 Chrome/네이버 응답에 따라 달라지므로 실제 URL에서 수집되지 않은 값은 가짜로 채우지 않습니다.
