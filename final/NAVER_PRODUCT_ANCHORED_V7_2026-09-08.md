# NAVER PRODUCT-ANCHORED V7 — 2026-09-08

## 목적
서로 다른 네이버 상품에서 수집 결과가 흔들리는 문제를 줄이고, 페이지 전체 JSON의 일반 UI 문구가 상품 데이터로 오인되는 회귀를 차단합니다.

## 변경
- 네트워크 JSON 전체에서 `name/price/image`를 무작위로 고르는 방식 제거.
- 입력 URL의 실제 상품번호(`/products/{id}`)를 기준으로 관련 상품 객체를 우선 탐색.
- 상품번호에 연결되었거나 상품 의미 키가 충분한 객체만 가격/배송/이미지/옵션 후보로 인정.
- `비밀번호 표시 삭제`, 로그인/검색/삭제/장바구니 등의 UI 문구를 상품명에서 강제 제외.
- `네이버`, `NAVER`, `스마트스토어`, `브랜드스토어` 등을 상점명으로 강제 제외.
- V4~V6에서 실제 DOM으로 성공한 상품명/상점명/대표이미지/옵션 경로는 유지.
- 렌더링 DOM에서 값이 비어 있을 때만 상품번호 기반 네트워크 데이터를 보완에 사용.
- 네이버가 페이지 내부 script에 상품 상태 JSON을 넣는 경우를 위해, 정확한 상품번호가 포함된 inline script만 제한적으로 캡처.
- 미수집 가격/배송비는 계속 빈값으로 유지하며 임의 0원 처리하지 않음.

## 내부 회귀 테스트
의도적으로 잘못된 UI JSON(`비밀번호 표시 삭제`, `네이버`, 999원)과 실제 상품번호에 연결된 정상 상품 객체를 함께 넣고 테스트했습니다.
정상 상품명/상점명/142,810원/배송비 0/이미지 3장/옵션 2그룹이 선택됨을 확인했습니다.

## PASS 기준
네이버 자체 PASS는 아직 아닙니다. 서로 다른 실제 네이버 상품 URL에서 1~7 필드가 반복적으로 정확하게 수집되는지 사용자 실환경 교차검증 후 PASS합니다.
