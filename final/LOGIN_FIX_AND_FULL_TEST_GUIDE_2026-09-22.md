# 로그인 수정 + 전체 기능 테스트 가이드

## 로그인 수정
- 로그인 유지 여부는 `/auth/me` 인증 결과로만 판단한다.
- 상품/재고/분석/대시보드 등 부가 화면 중 일부 로딩이 실패해도 정상 로그인 토큰을 삭제하지 않는다.
- 일부 화면 실패 시 로그인은 유지하고 실패 개수만 토스트로 알린다.
- 기존 외부 영구 DB는 삭제하거나 초기화하지 않는다.

## 로그인 우선 확인
1. 서버 실행: `python -m uvicorn app.main:app --reload`
2. 브라우저: `http://127.0.0.1:8000/web/`
3. 기존 일반 계정으로 로그인.
4. 일반 계정이 안 되면 기본 관리자 계정으로 로그인하여 프런트/서버 로그인 기능을 분리 점검.
5. 관리자도 안 되면 브라우저에 보이는 오류 문구와 CMD 오류를 확인.

## 전체 테스트 순서
1. 회원가입/로그인/로그아웃
2. 공급처 등록/수정/삭제/상품 연결 후 삭제 차단
3. 상품 등록/수정/삭제/SKU/검색/필터/정렬
4. 손익 계산/SELL-HOLD-STOP/손익분기점/권장판매가/SELL SCORE
5. 재고 최소수량/입고/출고/부족재고/이력
6. 통합 대시보드/활동 로그/리스크/세금 참고 계산
7. CSV/XLSX 템플릿/대량 등록/내보내기
8. FREE/PRO 사용량
9. 관리자 대시보드/사용자 목록/요금제 변경
10. 사용자 계정 2개 데이터 격리
