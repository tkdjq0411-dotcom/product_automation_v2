# 네이버 자동판단 1/5단계 완성 V59

## 1단계 완료 범위

- 화면 수집값과 내부 상태값을 하나의 전달 형식으로 통합
- 실제 전체 상품명 정리 및 오류·로그인 쉘 문자열 차단
- 가격과 배송비를 숫자 형식으로 통일
- 비정상 결합 가격이 다른 정상 가격 후보보다 5배 이상 크면 정상 후보 선택
- 이미지 URL 표준화, 크기용 `type` 파라미터 제거, 중복·로고·아이콘·스크립트 제거
- 일반옵션, 추가옵션, 부모·자식 조합을 서로 분리된 스키마로 유지
- 동일 그룹·동일 옵션값·동일 부모자식 조합 중복 제거
- 이름만 있는 옵션과 가격이 있는 동일 옵션이 충돌하면 가격 포함 값 보존
- 브라우저 전달 직전과 서버 수신 경계에서 이중 표준화

## 회귀검사

- 확장프로그램 JavaScript 구문검사: 통과
- FastAPI 전체 Python 컴파일 검사: 통과
- 브라우저 표준화 자동검사: 7/7 통과
- 서버 표준화 독립검사: 4/4 통과
- 기존 최대 2회 확인, 전체 최대 2분, 구매버튼 방지 구조 유지
- SQLite DB 구조 및 기존 영구 데이터 변경 없음

## 버전

- 전체 프로젝트: V59
- Chrome 확장프로그램: 2.46.0
