# 네이버 상품 영역 정확 수집 보강

URL 소싱의 네이버 Chrome 수집기는 페이지 전체의 유사 텍스트/이미지를 무작위로 수집하지 않고 상품 구매 영역과 상품 갤러리를 기준으로 다음 값을 분리해 수집한다.

- 상품명: 구매영역의 실제 상품명
- 공급처: `네이버-실제 스토어명`
- 매입가: 취소선 정가가 아닌 최종/최대 할인가 우선
- 배송비: 무료배송은 0, 유료배송은 실제 금액
- 대표 이미지: 상품 갤러리 첫 이미지
- 상품 이미지 전체: 좌측 상품 갤러리의 이미지 장수 그대로
- 옵션: 실제 옵션 드롭다운을 열어 표시되는 옵션값을 그룹별로 수집
- 공급상태: 구매 가능/품절 상태

추천상품, 상세페이지 이미지, 배너, 네이버 공용 UI 이미지는 상품 갤러리에서 제외한다.
