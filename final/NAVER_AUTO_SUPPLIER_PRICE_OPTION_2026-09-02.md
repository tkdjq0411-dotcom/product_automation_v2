# 네이버 URL 자동소싱 자동설정 보강

URL 입력 후 실제 페이지/브라우저 네트워크 응답에서 다음 항목을 자동 추출하도록 보강했습니다.

- 플랫폼/상점명 및 `네이버스토어 - 상점명` 공급처명 제안
- 동일 상점 공급처 자동 재사용, 없으면 소싱 저장 시 자동 생성
- 매입가
- 배송비(무료 포함)
- 공급 상태
- 옵션 그룹/옵션값
- 옵션 조합별 ID/가격/추가금/공급상태(페이지에 노출된 경우)
- 대표/상세 이미지, 상품번호, 원본 URL

가짜 값은 생성하지 않으며 페이지/브라우저가 실제로 받은 데이터만 저장합니다.
