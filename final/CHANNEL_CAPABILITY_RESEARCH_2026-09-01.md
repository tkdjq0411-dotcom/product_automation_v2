# 판매채널 공식 API 가능 범위 조사 (2026-09-01)

## 네이버 커머스API
- OAuth2 Client Credentials 인증
- 주문 변경 내역 조회
- 상품 주문 상세 조회
- 상품 등록/조회/수정
- 판매 상태 변경
- 멀티 상품 변경(판매가/재고/할인/판매상태)
- 발송 처리

## 쿠팡 Open API
- HMAC-SHA256 인증
- 상품 생성/조회/수정 계열
- 발주서 목록 조회(분단위/일단위)
- 주문 단건 조회
- 상품준비중 처리
- 송장 업로드/업데이트
- 배송상태 히스토리 조회

## 현재 프로젝트 적용
이번 버전은 실제 키를 안전하게 서버 환경변수에서 읽고 네이버/쿠팡 API에 연결할 수 있는 인증/호출 기반을 구현했다.
실제 키가 없는 상태이므로 외부 계정 호출 성공 여부는 사용자 키 입력 후 설정 화면의 API 연결 테스트로 검증한다.
